About this console

This is a read-only, normalised REST layer in front of the legacy Urja Meter Ops portal. The server keeps the portal session, signs the bulk export, repairs inconsistent hierarchy fields and converts cumulative registers into interval usage.

Freshness is controlled by a short-lived dataset snapshot. The X-Cache and X-Data-Fetched-At response headers tell you whether a request was served from cache and when the source was read.
